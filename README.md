# Магазин «Корзинка»

3D-супермаркет от первого лица в браузере: катишь тележку между рядами, собираешь товары по списку, общаешься с покупателями и оплачиваешь на кассе.

Сайт статический: вся игра лежит в `index.html`, Three.js и шрифты подключаются с CDN.

## Управление

- `W` `A` `S` `D` — катить тележку, `Shift` — быстрее
- Мышь — смотреть по сторонам
- `E` или клик — взять товар, поговорить, оплатить на кассе
- `Q` или правая кнопка — вернуть последний товар
- `M` — звук

## Запуск локально

```bash
python -m http.server 8765
```

Открой http://localhost:8765.
